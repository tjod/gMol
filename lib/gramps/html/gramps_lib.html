The gramps library

The gramps library contains some useful picture files and command files. These files are included with the gmol application. Gramps commands can be entered in the commands tab of gmol's top-menu View/Gramps window.
For example:
  • get ssphere !reads the file ssphere.pix
  • blue ssphere !does the file blue.gin
