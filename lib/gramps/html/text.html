TEXT

The text command is used to draw text characters on the screen. The syntax of the command is:

text STRING name value,value,value

STRING is any string of one or more characters. If STRING is to contain DELIMITERs (blanks or commas) it must be enclosed in double quotation marks. If the string contains lower case letters, even if it contains no DELIMITER characters, it should also be enclosed in double quotation marks to ensure no translation to upper case is done. name must be a new name not already known to the system.

The values are interpreted as X, Y, and Z coordinates for placement of the lower left corner of the first character in STRING. These values are optional. For the values which are omitted, an assumption is made. If the X or Y coordinate is missing, then the default value of 0 is used. If the Z coordinate is missing, the default value used is 0.

You can also specify the coordinates using a picked point variable, e.g. #1.

The object created will have all 3D transformations applied to it, but only to the lower-left corner coordinate, not to the body of the text itself. The text will always appear front-facing and remain the same size. You can translate this text after it is created. If you want a smaller or larger size, use the /size switch.

/size=nn

The /size=nn switch, with a required number nn, will produce larger or smaller text. The default size is 36.

/3D

The /3D switch creates a 3D object having the text string extruded into the Z-dimension. This is an ordinary gramps 3D object. It is transformed like any other gramps object. It will NOT always remain front-facing. The /size switch applies as well, but this text can be scaled after it is created, unlike the default text.

/2D

The /2D switch creates a flat 3D object. This is an ordinary gramps 3D object, albeit flat. It is transformed like any other gramps object. It will NOT always remain front-facing. The /size switch applies as well, but this text can be scaled after it is created, unlike the default text.
